## Download
1. Go to this link: https://archive.ics.uci.edu/dataset/296/diabetes+130-us+hospitals+for+years+1999-2008
2. Click 'Download'
3. Extract `diabetic_data.csv` and `IDS_mapping.csv`
4. Place both files in this folder
